# Gotcha!

Gioco mobile Android di enigmi "a trabocchetto", sviluppato in Unity (C#).

Livelli attuali:
1. **Pinch & Open** — rimpicciolisci la chiave col pizzico e infilala nella serratura.
2. **Tilt Maze** — inclina il telefono per guidare la sfera dall'esterno al centro del labirinto.
3. **Snowman** — dai una faccia al pupazzo di neve: occhi e naso sulla testa, il sorriso lo disegni col dito (con Easter egg sul sedere).
4. **Big Red Button** — dai al gatto il pesce del quadro, poi lascialo dormire senza toccare niente.
5. **Slice It!** — taglia la mela con il dito.

Istruzioni per aprire il progetto e creare l'APK: vedi [README_SETUP.md](README_SETUP.md).
